IXYS100N170 - IXYS High Power IGBT Module

1700V, 100A, 2.0V VCE(sat) - Industrial Module Package

Key Specifications

  • Part Number: IXYS100N170
  • Series: High Power
  • Type: IGBT Module
  • Collector-Emitter Voltage (VCE): 1700V
  • Collector Current (IC): 100A
  • VCE(sat): 2.0V (max)
  • Package: High Power Module
  • Technology: Trench Field Stop
  • Applications: Industrial Drives

Product Description

The IXYS100N170 is a high-power IGBT module from IXYS' portfolio, designed for demanding industrial drive applications. With a 1700V rating and 100A current capability, this device offers exceptional performance in high-power variable frequency drives and industrial motor control systems.

This high-power module integrates multiple IGBT dies in a single package with optimized thermal characteristics. The device combines the advantages of IXYS' Trench Field Stop technology with robust packaging suitable for industrial environments. It features enhanced thermal cycling capability and improved long-term reliability.

  • Heavy Machinery Control
  • Compressor Drives
  • Pump Systems
  • Conveyor Systems
  • Extruder Drives
