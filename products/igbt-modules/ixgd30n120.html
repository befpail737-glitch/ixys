IXGD30N120 - IXYS Application Optimized IGBT

1200V, 30A, 2.1V VCE(sat) - TO-247 Package

Key Specifications

  • Part Number: IXGD30N120
  • Series: Application Optimized
  • Type: IGBT
  • Collector-Emitter Voltage (VCE): 1200V
  • Collector Current (IC): 30A
  • VCE(sat): 2.1V (max)
  • Package: TO-247
  • Application: Motor Drives
  • Gate Charge (Qg): 120nC

Product Description

The IXGD30N120 is an Application Optimized IGBT from IXYS' portfolio, specifically designed for motor drive applications. With a 1200V rating and 30A current capability, this device offers optimized characteristics for variable frequency drives and servo systems.

As part of the Application Optimized series, the IXGD30N120 is tailored for motor drive applications with optimized gate charge and switching characteristics. The device features a balance between conduction and switching losses optimized for motor drive duty cycles, providing superior performance in variable speed drive systems.

Applications

  • Industrial Motor Drives
  • Servo Systems
  • Variable Frequency Drives (VFD)
  • Pump and Fan Control
  • Conveyor Systems
  • Robotics
