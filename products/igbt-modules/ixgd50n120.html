IXGD50N120 - IXYS Application Optimized IGBT

1200V, 50A, 2.1V VCE(sat) - TO-247 Package

Key Specifications

  • Part Number: IXGD50N120
  • Series: Application Optimized
  • Type: IGBT
  • Collector-Emitter Voltage (VCE): 1200V
  • Collector Current (IC): 50A
  • VCE(sat): 2.1V (max)
  • Package: TO-247
  • Application: Welding
  • Gate Charge (Qg): 180nC

Product Description

The IXGD50N120 is an Application Optimized IGBT from IXYS' portfolio, specifically designed for welding equipment applications. With a 1200V rating and 50A current capability, this device offers optimized characteristics for inverter welding systems with high efficiency and reliability.

As part of the Application Optimized series, the IXGD50N120 is tailored for welding applications with enhanced ruggedness and optimized switching characteristics. The device features excellent short-circuit capability and thermal cycling performance required in the harsh welding environment. It provides a balance between conduction and switching losses optimized for welding duty cycles.

Applications

  • Inverter Welding Equipment
  • MIG/MAG Welding Systems
  • TIG Welding Systems
  • Stick Welding Systems
  • Plasma Cutting Equipment
  • Industrial Power Supplies
